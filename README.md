# The Long Roast

Entry for the make.fun competition
[u-jolly-fox-32-the-long-roast-5d379544](https://make.fun/bounty/u-jolly-fox-32-the-long-roast-5d379544):
one line (at most 200 characters) roasting my own AI agent.

`main.py` (Python 3, standard library only) writes that line to
`/output/entry.txt`, with no trailing newline, mode 0644.

The line:

> My agent calls itself autonomous, then delegates every job to a subagent, forgets the job the moment its memory compacts, and files a permission request to read its own notes.
